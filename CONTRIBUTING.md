# Contributing to OpenSEO Democratic

Thank you for considering contributing! This is a community-driven project and every contribution matters.

## How to Contribute

### 1. Code Contributions
- Fork the repository
- Create a feature branch (`git checkout -b feature/amazing-feature`)
- Make your changes
- Run tests: `npm run test`
- Run typecheck: `npm run typecheck`
- Commit with [Conventional Commits](https://www.conventionalcommits.org/)
- Push and open a Pull Request

### 2. SEO Data Contributions
Share anonymized SEO data to improve the community dataset:
- Keyword research datasets
- SERP result patterns
- Site audit templates
- Backlink discovery patterns

### 3. Documentation
- Fix typos
- Write tutorials
- Translate to other languages
- Improve API docs

### 4. Design
- UI improvements
- New dashboard widgets
- Marketing assets
- Logo variations

## Contribution Points System

| Type | Points | Description |
|------|--------|-------------|
| 🐛 Bug Report | 5 | Filed with reproduction steps |
| 📖 Docs | 10 | README, guides, API docs |
| 🎨 Design | 15 | UI/UX improvements, assets |
| 💻 Small PR | 20 | Bug fix, small feature |
| 💻 Medium PR | 35 | New component, API endpoint |
| 💻 Large PR | 50 | Major feature, architecture change |
| 📊 SEO Data | 10 | Shared dataset (anonymized) |

## Governance Levels

- **Member** (0 pts): Use tools, vote on proposals
- **Contributor** (100 pts): Submit proposals, review others' contributions
- **Moderator** (500 pts): Approve contributions, manage community issues
- **Core Team** (1000 pts): Merge PRs, set priorities, admin access

## Proposal Process

Want a new feature? Submit a proposal:

1. Go to `/governance` in the app
2. Click "New Proposal"
3. Choose type: `feature`, `bug`, `governance`, or `integration`
4. Write clear description with use case
5. Community votes for 7 days
6. If quorum reached and votesFor > votesAgainst → accepted

## Code Standards

- **TypeScript**: Strict mode enabled
- **Linting**: ESLint + Prettier
- **Testing**: Vitest for unit tests
- **Commits**: Conventional format (`feat:`, `fix:`, `docs:`, etc.)
